CADCheckTool v2.2.0 安装说明
================================

适用环境
--------
操作系统：Windows 10/11 x64
AutoCAD：AutoCAD 2024
运行环境：.NET Framework 4.8

安装步骤
--------
1. 保存所有图纸并完全关闭 AutoCAD。
2. 双击 CADCheckTool_1_Setup_v2.2.0.exe。
3. Windows 出现用户账户控制提示时点击“是”，按安装向导完成安装。
4. 重新启动 AutoCAD 2024。
5. 在 AutoCAD 命令行输入 CHECKDRAWING 打开程序。

安装位置
--------
安装程序会把完整插件包安装到当前 Windows 用户的：

C:\Program Files\Autodesk\ApplicationPlugins\CADCheckTool.bundle

AutoCAD 会把 Program Files 下的 bundle 作为受信任插件自动识别，因此不需要执行 NETLOAD，也不需要手动修改注册表。安装程序还会移除旧版本创建的 CADCheckTool_1 自动加载注册表项，避免新旧版本重复加载。

外部数据设置
------------
首次使用时，请在 CADCheckTool 的“路径设置”中确认：

1. 标准件 Excel 数据库路径；
2. 非标件归档路径；
3. 版本检查归档路径。

配置和日志保存在：

%APPDATA%\Correct_test1

卸载
----
打开 Windows“设置”→“应用”→“已安装的应用”，找到 CADCheckTool 2.2.0 后卸载。

注意事项
--------
1. 安装、升级或卸载时必须先关闭 AutoCAD，避免插件 DLL 被占用。
2. 本安装包只支持 AutoCAD 2024，不会安装或替换 AutoCAD 自带的 AcMgd.dll、AcDbMgd.dll、AcCoreMgd.dll。
3. 如果 AutoCAD 仍提示安全加载，请确认安装目录已完整生成，并重新启动 AutoCAD。
