# CADCheckTool v2.2.0 Generalized Release Notes

## 发布定位

这是从 `generalized-tool` 分支构建的通用化预发布版本，不会替代公司版本 `v2.2.0`。

本版本保留 CADCheckTool 2.2.0 的检查、批处理、安全保存、自动加载和快速划改能力，并将公司专用信息替换为中性示例：

- 非标图号前缀示例：`AB`
- 项目号规则示例：`P####AA###`
- 图纸归档路径占位值：`（所查图纸范围）`
- 标准件数据库占位值：`（标准件比对库）`
- 发布者及许可证信息使用中性名称

## 使用前必须配置

该版本不是下载后即可适配所有企业图纸的成品。首次部署前必须根据实际图纸标准核对并调整：

- 横向、竖向标题栏区域和字段坐标
- BOM 表头、列映射及零件号格式
- 图号、项目号和版本号规则
- 修改记录表结构
- 检查标记图层与尺寸
- 标准件 Excel 的列结构
- 归档文件命名和搜索规则
- 典型样图回归测试

具体修改位置见仓库中的 `GENERALIZATION_GUIDE.md` 和 `CONFIGURATION_GUIDE.md`。

## 运行环境

- Windows 10 1809 或更高版本，64 位
- AutoCAD 2024（R24.3），64 位
- .NET Framework 4.8
- 企业归档目录与标准件 Excel 的读取权限

## 主要功能

- 标题栏、BOM、标准件、非标件、序号、修改记录和版本归档检查
- 单张与批量检查、标记、清除和 CSV 导出
- 项目版本写入和快速划改
- 批量图纸安全保存、临时文件验证和日志记录
- Autodesk ApplicationPlugins 按需自动加载

## 已知边界

- 当前规则仍包含模板坐标、命名正则和几何容差等编译期配置。
- 未完成模板适配和样图回归前，不建议直接用于生产图纸。
- 不支持 AutoCAD 2025 及更高版本；这些版本需要 .NET 8 专用构建。
