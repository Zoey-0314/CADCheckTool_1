01 · Core capabilities

覆盖工程图审核的关键环节

从 DWG 内的标题栏、修改记录到 BOM 与标准件信息，CADCheckTool 将分散、重复、依赖经验的检查动作转为可配置、可执行的工程规则。

01

工程图检查

检查图号一致性、标题栏字段完整性、修改记录与项目号基础逻辑，降低人工目检遗漏。

02

BOM 智能读取

通过 CadTableReader 与 BomTableRecognizer 读取 CAD 表格，解析 BOM 数据并提取零件信息。

03

标准件校验

连接 StandardParts.xlsx 标准件库，支持图号索引、宽松匹配、格式与名称校验、缺失及多匹配检测。

04

图内可视化标记

在专用 Marker 图层生成问题定位标记，以 XData 关联来源，并支持安全清除和重复检查。

02 · Inspection workflow

从读取到反馈，构建闭环审核

项目遵循清晰的职责边界：读取器专注采集 CAD 数据，检查器执行业务规则，标记系统只负责将结果可靠呈现在图纸中。

03 · Layered architecture

分层架构，职责清晰

以“读取数据 → 分析数据 → 生成结果 → 修改 CAD”为设计原则，避免模块越界造成的耦合与风险。

ReadersDWG / BOM / 标题栏 / 修改记录读取
Checks图号、项目号、BOM、标准件规则校验
Markers问题标记、XData 关联、标记生命周期
Core · Batch · Export日志、安全保存、批处理与结果导出
